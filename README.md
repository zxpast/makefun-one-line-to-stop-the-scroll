One line of text that makes a stranger stop scrolling and smile: a fridge lock, and the cat who hired a locksmith.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` writes the entry to `$MAKEFUN_OUTPUT_DIR/entry.txt`. Node 22 standard library only, fully deterministic: same bytes on every run, no network, no randomness, no clock reads.
